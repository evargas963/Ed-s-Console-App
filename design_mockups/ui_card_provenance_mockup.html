UI card provenance — design mockup
Per ACTIVE_PROGRAM.md §UI card provenance spec · Issue 18 card system

This is a static render of the proposed design — no live data, no JS wiring. Every chip, strip, line and banner here will be driven by existing API payload fields (mhap_rows[], canonical_provenance, stack_integrity_v1.degraded, horizon_fusion_available, horizon_prob_bars) once approved. Existing .tf-signal-card chrome, Horizon alignment slots, Decision Rail and tf-signal-card--trade-active color semantics are preserved.

Layout order (top → bottom, within one card row):
  1. Horizon row — 4 pills (1M / 5M / 15M / 60M). Each pill: direction + confidence + source chip + sample count when EMPIRICAL.
  2. Signal rail card — unified below the row. Top half = fusion verdict (direction + agreement) when fusion is tradable, or "Not tradable — empirical context only" otherwise. Bottom half = empirical context (tier label, N similar setups, up/down/flat probs); muted when ML is authoritative, foreground when empirical is the only signal.
  3. Integrity status tags — inline in the signal rail card top: ⚡ ENTRY ARMED (solid green) when primary horizon fires; ⚠ STACK DEGRADED (solid red) when stack_integrity_v1.degraded. Same shape language, opposite verdicts.

Design notes
  1. Chip is the single source-of-provenance signal per pill — three pipelines do not collapse into one number without it. Existing PRIMARY/AGREE/CONFLICT tag remains below (Decision Rail alignment), but chip is now the dominant interpret signal.
  2. Color contract: blue/cyan = history, green = stack, gold = blend, gray = absent, red = degraded. Degraded is red — never gray — so it cannot read as "WAIT setup."
  3. UNAVAILABLE in WAIT/neutral pills: card chrome stays slate-blue (operator legibility — same as existing tf-state-dim), not grayscale-washed.
  4. Fusion strip only when fusion is tradable: gated on canonical_provenance === 'bayesian_fusion' (existing isCanonicalTradable). Otherwise the "Not tradable — empirical context only" line takes its slot so the row never empties.
  5. Empirical line always renders when N>0 — muted opacity 0.62 when ML is authoritative (Scene A), foreground when empirical is the only signal (Scenes C/D).
  6. Degraded banner is row-level (full-width red bar above the cards), distinct from the existing small #dr-stack-integrity-degraded-chip in the Decision Rail header — same backing field, two surfaces for different audiences.
