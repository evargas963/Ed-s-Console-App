description: Self-administered audit protocol. Run BEFORE signing off ANY audit, stage acceptance, or "MET/clean/verified" claim — especially when auditing another agent's work. Invoke whenever about to claim work is correct/complete.
---

Check the change against `AGENTS.md` on the real repository state, under its "Claims" rule (CONFIRMED only by command output in the same reply, everything else NOT VERIFIED): every rule, "Before writing code", "Before saying done", "Close the change". Report in the form of its "Review verdicts" section (PASS / FAIL / NOT_PROVEN, the tier of each proof). The standard has one home, `AGENTS.md`; this skill carries no copy.
