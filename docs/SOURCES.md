## The Schwab field list

The First gate's Schwab field list is `docs/schwab_fields.csv`: every field path Schwab has sent us
(`python -m tools.schwab_field_inventory`), its type, a sample and `schwab_doc`, where Schwab's
documents define it. Schwab's definitions are in the Streamer guide (schwab-streamer-guide: each
stream field, and whether it updates in AM/PM hours and when it resets) and the Market Data API
(schwab-market-data-spec and the expanded parameter files). `/chains` rounds Greeks to 3 decimals,
which is why a contract's Greeks come from the stream or `/quotes` (`docs/DATA_FLOW.md` §3.4).
