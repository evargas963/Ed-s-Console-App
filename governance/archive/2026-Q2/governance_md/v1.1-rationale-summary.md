**Change:** Step 0 — locked items vs moving parts (with change paths).  
**Rationale:** Separating what requires a framework version bump from what can move inside a prereg amendment prevents silent “documentation drift” while still allowing frozen numerical grid edits.  
**Evidence:** `7c88fec78d8b4f4c6d24c3819e3a94a5b68d7da9` — `governance/Framework-ED-Decision-Engine-v1.1.md` (Purpose, Step 0, changelog §[1.1]).

**Change:** Framework ↔ prereg bidirectional coupling and runtime hard-fail.  
**Rationale:** The markdown framework and `research/pilot_step3/prereg_v1.json` are only jointly authoritative when `content_hash`, `framework_doc_id`, and `framework_doc_version` line up; loaders enforce that so consumers cannot run half-bound artifacts.  
**Evidence:** `7c88fec78d8b4f4c6d24c3819e3a94a5b68d7da9` — `research/pilot_step3/prereg_v1.json`; `research/pilot_step3/pilot_config.py` (`validate_prereg_integrity`, `validate_framework_binding`, `EXPECTED_FRAMEWORK_DOC_ID` / `EXPECTED_FRAMEWORK_DOC_VERSION`); `governance/Framework-ED-Decision-Engine-v1.1.md` (footer coupling).

**Change:** ATR T−1 rationale in Step 1.5; Step 5.5 enforcement-only.  
**Rationale:** The “why” belongs with trade-definition semantics (bias control); execution bullets stay short so implementers do not re-litigate rationale in code comments.  
**Evidence:** `7c88fec78d8b4f4c6d24c3819e3a94a5b68d7da9` — `governance/Framework-ED-Decision-Engine-v1.1.md` (Steps 1.5, 5.5); `research/pilot_step3/prereg_v1.json` (`atr`); `research/pilot_step3/labeling.py` (barrier width uses prior-bar ATR per prereg).

**Change:** Cost model IDs as reproducibility contract (`v1` / `v2_underlying` / `v2_options`).  
**Rationale:** Naming which cost schema ran is a reproducibility and comparator-integrity obligation, not a discretionary knob to turn after seeing the barrier grid.  
**Evidence:** `7c88fec78d8b4f4c6d24c3819e3a94a5b68d7da9` — `governance/Framework-ED-Decision-Engine-v1.1.md` (Step 4); `research/pilot_step3/prereg_v1.json` (`costs`).

**Change:** Instrument tiers and validation sequence (SPY → QQQ → mega-cap → broader).  
**Rationale:** Liquidity and microstructure assumptions do not transfer down the tier list; an explicit sequence makes over-claiming harder.  
**Evidence:** `7c88fec78d8b4f4c6d24c3819e3a94a5b68d7da9` — `governance/Framework-ED-Decision-Engine-v1.1.md` (Step 8); `research/pilot_step3/prereg_v1.json` (`instrument`).

**Change:** Meta-labeling elevated to Step 1 (primary vs secondary layers).  
**Rationale:** Candidate trade outcomes stay the primary supervised layer; meta is explicitly a filter over candidates so scope creep is visible in the framework skeleton.  
**Evidence:** `7c88fec78d8b4f4c6d24c3819e3a94a5b68d7da9` — `governance/Framework-ED-Decision-Engine-v1.1.md` (Step 1, Step 16).

**Change:** Pre-registration spine, DSR / multiplicity gate, and contracts appendix (“contracts primary, code projection”).  
**Rationale:** Prereg is the anti–post-hoc spine; DSR/multiplicity is non-negotiable before “cell” language; Appendix A ties the narrative to V3 invariants and controlled vocabulary without duplicating that standard in full here.  
**Evidence:** `7c88fec78d8b4f4c6d24c3819e3a94a5b68d7da9` — `governance/Framework-ED-Decision-Engine-v1.1.md` (Step 1 prereg spine, Step 7, Appendix A); `research/pilot_step3/prereg_v1.json`; `tests/test_pilot_prereg_framework_binding.py` (integrity hard-fail behavior).
